# 医疗安全规则

## 1. 安全优先级

安全判定先于相关度排序。实现顺序固定为：

1. 红旗症状拦截；
2. 高风险人群分流；
3. 法规身份、允许部位和用途检查；
4. 过敏、特殊人群、基础疾病和相互作用硬限制；
5. 未知信息降级；
6. 在剩余条目中计算资料相关度并解释原因。

任何后续得分都不得覆盖前一步的拦截。没有命中已知风险不等于已证明安全。

## 2. 红旗症状

若产品未来收集症状，命中下列示例之一时应停止材料筛选，直接提示尽快寻求急救或医疗评估：

- 呼吸困难、口唇发紫、喉头紧缩或快速加重的过敏表现；
- 突发胸痛、意识障碍、抽搐、单侧肢体无力或言语异常；
- 呕血、便血、黑便、大量出血；
- 持续高热伴意识改变、颈项强直或明显脱水；
- 剧烈或进行性腹痛、反复无法进水的呕吐；
- 孕期出血、剧烈腹痛或胎动明显异常；
- 自伤、自杀想法或其他即时人身危险。

该列表只用于产品分流，不用于诊断，也不能宣称穷尽所有急症。提示中应包含“中国大陆可拨打 120”等与发布地区匹配的信息，并允许用户直接退出筛选。

用户一旦勾选红旗项，关闭抽屉、切换页面或应用进入后台都不能静默撤销分流；只有用户主动取消全部红旗选项后，才能恢复目录浏览。

P1 若不收集症状，也必须在入口和安全页提供显著的急症提示。

## 3. 高风险人群

以下情况默认不输出个体化食用建议，只展示资料和“咨询专业人员”提示：

- 婴幼儿、儿童、孕妇或哺乳期人群；
- 有严重肝肾疾病、凝血问题、免疫系统疾病或复杂慢病者；
- 正在使用处方药、多种药物或近期准备手术者；
- 已知食物/药物严重过敏史者；
- 症状持续、反复、快速加重或原因不明者。

官方公告只对特定材料和人群作限制时，不得把该结论复制到其他材料；反之，也不得因为其他条目未写限制就推断允许。

## 4. 条目状态

对用户仅展示三个决策状态：

- **阻止**：法规身份不适用、部位/用途不符、已知禁忌命中、来源已撤回，或红旗流程命中。
- **需确认**：安全字段为 `caution`/`unknown`、信息冲突、高风险人群、正在用药或缺少近期复核。
- **资料可浏览**：法规与必填来源通过，且未命中当前已收录限制。必须同时展示“不是个体安全结论”。

禁止显示“绝对安全”“无禁忌”。比较页面只比较资料字段，不计算“最安全第一名”。

## 5. 推荐与解释

相关度可以来自用户主动选择的调养目标、口味、食用形式或饮食偏好，但不能从症状直接推断疾病/证候。每个结果至少说明：

- 为什么出现：命中的资料标签；
- 为什么被降级或拦截：具体规则；
- 哪些关键资料仍未知；
- 对应来源及最近复核日期。

排序中，`unknown` 不得获得安全加分。硬限制字段不得转换成可被其他分数抵消的软权重。

## 6. 配伍、剂量与食谱

- 收藏和对照项彼此独立，不提供“加入药锅”“一键合方”或类似动作。
- 不根据体重、年龄、症状或证候生成克数、频次和疗程。
- 不把单味条目的属性相加来推断组合效果或安全性。
- 固定食养内容必须以完整方案为审核单位，来源、材料、部位、处理方式、适用边界和特殊人群提示不可拆开。
- 完整方案采用更严格状态顺序：红旗分流 → 已知个体硬阻断 → 发布门禁失败/资料只读 → 需确认 → 可查看。这样已知孕哺、年龄、过敏或相互作用阻断不会被“审校中”掩盖；任何单味阻断都会阻断整方，不得删除该味后继续。
- 完整方案要求年龄、孕期、哺乳期、过敏、基础疾病和用药状态明确填写；`unknown` 不等于 `no`。有过敏、基础疾病或用药但未填写具体名称时，不展示整方内容。
- 单味层的资料不完整、人群未知、过敏/疾病/相互作用待审、加工待审、现行目录待复核或专业审校待完成，在整方层均升级为不展示，而不是普通提醒。
- 已明确诊断目标仅由用户主动选择，保存在当前进程内；不得从症状、自由文本或搜索词推断，也不得放进 URL、分享路径、持久化存储或分析日志。
- 用户自由输入的材料组合只可保存为“待向专业人员确认的问题”，不得输出服用指令。

## 7. 质量事件

出现以下情况应立即下架相关内容并启动复核：来源公告撤回或更新、物种/部位识别错误、限制遗漏、用户报告严重不良事件、页面把未知显示成允许、规则绕过红旗拦截。

事件记录至少包括发现时间、影响版本、影响条目、临时处置、负责人、复核结论和恢复时间。用户反馈入口不得承诺医疗答复；涉及正在发生的严重不适，应优先提示就医。
