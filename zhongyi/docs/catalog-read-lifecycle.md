# 服务目录读取与页面返回恢复

首页在读取服务目录期间离开，再于请求结束前返回，现可接收原请求的成功、失败或超时结果，不会一直显示读取中。返回页面只观察正在进行的请求，不自动联网；本地查阅、原有安全过滤和明确选择本地资料的操作保持可用。

## 问题与修复

原先隐藏页面会清除读取令牌，防止迟到回调更新离开的页面；重新显示时只读取当时的客户端状态。如果请求尚未结束，页面得到 `loading`，随后原回调又因令牌失效而被忽略。客户端虽已完成，界面却没有收到结果，读取按钮持续禁用。

[目录客户端](../utils/public-catalog.js)新增只读的 `getPendingRead()`，仅返回已有 Promise 或空值，不启动、重启或修改请求。[首页](../pages/index/index.js)显示时先重查当前会话与本地状态，再为已有请求建立当前页面的观察令牌。用户主动读取也复用同一观察处理。

完成回调仍须同时满足页面可交互、当前令牌一致、删除修订一致及会话上下文一致。多次离开返回只有最新令牌生效；隐藏或卸载的旧页面不接收更新。切回本地及隐私页明确删除仍取消请求，迟到结果不得恢复缓存、查询或健康信息。请求只读取固定公开目录，仍不带搜索词、收藏或健康问项。

## 联网按钮与会话状态保护

2026-10-09，首页两个联网按钮绑定当前交互版本，处理函数先刷新会话，再核对事件版本。开始读取、请求完成、主动切回本地、前后台、问项变化或隐私删除后，旧按钮不能发起另一轮读取或取消后来明确开始的请求。正常的当前按钮仍可取消、主动重试；不自动重试、不改变原有6000毫秒传输超时及6250毫秒独立截止。

读取中会话画像变化会使原观察令牌失效。此时刷新会话后重新观察同一个已有请求，避免客户端完成而界面停在读取中；不重发请求、不恢复旧画像。红旗、安全/筛选遮罩、卸载、隐私删除及本地切换仍优先。取消不清空查询、当前资料、收藏、对照或内存准备进度，固定公开GET及无健康字段边界保持不变。
