# 产品边界：中医食养筛选助手

## 1. 产品定位

本项目是一款**非医疗的食养知识与安全筛选工具**。它帮助用户在普通食品及当前有效的官方食药物质目录内：

- 按调养目标、饮食偏好和材料属性检索资料；
- 查看材料的规范身份、可食部位、食用限制、注意事项和出处；
- 收藏或并列对照材料；
- 整理需要向医生、药师或营养专业人员确认的问题。

筛选结果表达的是“资料相关性”和“是否触发已收录的安全限制”，不是疗效排序，也不是适合个人服用的医学结论。当前版本按官方批次快照覆盖 106 个食药物质名称，但该数字只属于 `2026.08-full-catalog.1` 的核对结果，不是永久常量；官方目录变化时必须建立新快照、重新审核、版本化并发布。

## 2. 明确不提供的能力

本项目不得：

- 诊断疾病、判断证候或替代线下/互联网医疗服务；
- 根据症状自动开具处方，或输出剂量、用法、疗程；
- 将若干单味材料自动组合成方剂、药膳或煎煮方案；
- 声称食品能够预防、治疗疾病，或者承诺疗效；
- 将收藏、对照或排序结果描述成“可以一起服用”“最佳搭配”；
- 对儿童、孕妇、哺乳期人群、肝肾功能异常者、多药并用者等高风险人群作个体化用药决定；
- 将“尚无资料”“未收录风险”表达成“安全”“无禁忌”。

固定食谱若在后续版本出现，只能来自可追溯的权威公开资料，或由具备相应资质的中医师、药师对完整配伍、用量、适用边界和文本进行审校；收藏的单味材料不得自动进入固定食谱。

## 3. 用户路径边界

| 页面 | 允许 | 禁止暗示 |
| --- | --- | --- |
| 食养目录 | 搜索、受控筛选、显示匹配理由和安全状态 | “治某病”“命中症状即可服用” |
| 条目详情 | 身份、法规状态、传统食养资料、安全边界、字段级来源 | 个体诊断、剂量和疗程 |
| 收藏 | 保存感兴趣的条目 | 收藏即代表适合使用 |
| 对照 | 最多四项资料横向对照 | 对照项可以共同食用或自由配伍 |
| 安全清单 | 汇总风险提示和待咨询问题 | 自动生成处方、方剂或煎煮单 |
| 官方完整方案目录 | 由用户主动选择已由医疗机构确诊的成人目标，查看整方审校状态 | 从症状推断疾病、自动辨证或把草稿当成可用方案 |
| 官方方案详情 | 仅在来源、材料身份、整方安全和专业签审全部完成后，整体呈现官方原始资料 | 在待审状态展示材料、用量、做法，或允许删改、替换、缩放和拼接 |

## 4. 文案规则

推荐使用：

- “与所选调养目标相关的资料”
- “未触发当前已收录的限制；仍需结合个人情况确认”
- “资料未知/待核实”
- “该人群不进入筛选建议，请咨询专业人员”
- “传统食养资料不等同于现代医学疗效结论”

不得面向用户使用：

- “治愈、根治、药到病除、保证有效”等疗效承诺；
- “确诊为、你属于某证型”等诊断结论；
- “每日服用 X 克、连续 X 天”等个体剂量或疗程指令；
- “把收藏的材料一起煎服、自动配方、一键开方”等处方或自由配伍指令；
- “绝对安全、无副作用、人人适用”等无条件安全承诺。

允许在边界声明、风险警示和治理文档中否定性地引用上述概念，但不得把它们作为功能、按钮或结果承诺。

## 5. 发布范围

2026-10 的全栈扩展允许配套管理端账号和小程序按需读取公开历史目录，但不增加用户诊疗或健康同步。小程序仅由 `utils/public-catalog.js` 请求固定只读接口，默认未配置而保持离线；来源和身份资料必须与本地内容版本一致，安全规则不从服务端覆盖。接口的“公开”表示无需后台登录即可读取既有展示投影，不代表获得正式内容发布许可；当前服务仅经本机工程验证。详见 [公开目录与离线回退](public-catalog-api.md)。

P1 开发预览可以载入已完成官方来源核对、但仍等待中医师和药师逐字段审校的种子条目；此类条目必须显著显示“需确认”，不得展示未经审校的传统功效。P3 的 86 个名称级补充条目只用于证明目录覆盖，不能因进入完整名称集合而获得身份、食用或安全审校状态。正式发布只接受已经完成身份核验、法规核验、安全字段三态化、来源记录和人工审校的展示字段。

P3 的官方完整方案草稿只允许显示名称、原始来源定位和发布门禁状态；材料、用量、制作方法和食用方式必须整体隐藏且不得进入上传包，直至材料身份、目录状态、食用形态/用途直接来源、整方安全以及中医临床、药学、营养、合规与最终发布批准审校全部通过。用户选择的确诊目标只保存在本次小程序进程内，不上传、不持久化，也不能由搜索词、症状或浏览行为推断。

如果未来要提供在线诊疗、辨证或处方能力，应由具备相应资质的医疗机构另立项目，完成执业人员、实名制、病历、处方、药师审方、监管和信息安全要求；不得通过修改当前页面文案直接扩大本产品边界。
