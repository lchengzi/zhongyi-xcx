# 小程序页面跳转可靠性

2026-10-08，目录、收藏、对照、安全清单、食材详情、官方方案目录和方案详情接入共用跳转保护。连续点击同一来源页面的入口只发起一次跳转；平台明确报告失败后提示重试，不自动重复打开。原有红旗与方案发布门禁继续在页面执行，跳转工具不授予内容查看权限。

## 页面状态与返回路径

[跳转模块](../utils/navigation.js)只提供固定站内入口：普通详情、官方目录/详情、隐私页，以及四个主包 tab。详情 ID 编码为单个查询值，空值、超长值和无法编码的值不发起跳转。

| 平台操作状态 | 处理 |
| --- | --- |
| 等待结果 | 保留来源页面的跳转锁；连续点击其他入口也不再发起跳转 |
| 已成功 | 包括隐藏期间收到成功，保留锁，直到来源页再次显示后解除，避免动画期间重复打开 |
| 可见页明确失败或同步异常 | 解除锁，显示“页面打开失败，请稍后重试”，允许用户主动重试 |
| 隐藏或卸载页发起操作 | 拒绝新跳转；迟到失败只释放对应旧状态，不回退跳转或提示 |
| 仅切回前台但原操作尚未返回 | 不把前台恢复视为跳转完成，不重复发起仍未确认结果的操作 |
| 来源页卸载 | 清理本页状态；迟到回调不能通知或改变后续操作 |

官方方案详情从方案目录打开时返回一层；冷启动直链则用 `redirectTo` 到目录，不额外压栈。可见页返回一层明确失败时只尝试一次目录重定向；重定向也失败才通知重试。来源已隐藏或卸载则不再回退。

跳转没有自动超时重发：计时结束不能取消微信已经开始的跳转，提前解锁可能再次打开同一页面。若平台始终不返回回调，本轮操作会保留锁，需要退出并重新打开小程序；本机模拟验证这个保守分支，不声称已在手机复现此平台异常。

## 隐藏页面与迟到回调修复

2026-10-09，共用跳转入口增加可见状态检查：隐藏或卸载页不能发起新跳转；原返回操作失败时，若来源已隐藏，不再重定向或显示迟到提示。隐藏期间收到成功仍记录成功，但只有再次显示才解除锁，避免提前重复打开。普通失败在可见页仍允许主动重试，不增加超时自动重发。

[跳转专项](../tools/test-navigation.js)由18项增至23项；新增隐藏/卸载入口、返回回退、迟到失败及隐藏期间成功恢复检查。[列表专项](../tools/test-list-actions.js)同时验证收藏、对照和安全页的目录/隐私辅助入口：隐藏时不跳转，重新显示后可正常操作。两组修复后合计67/67通过，零失败、跳过或取消；完整核心结果另见[当前状态](implementation-status.md)。这些受控接口结果不代表手机生命周期或微信返回栈已实测。

## 原始阶段验证

在 Windows、Node.js 22.15.1 运行：

```text
node tools/test-navigation.js
node tools/smoke-pages.js
npm run check
npm test
```

- [跳转专项](../tools/test-navigation.js)：18 项通过，0 失败、跳过或取消；覆盖重复点击、跨目标锁、失败与异常、返回恢复、迟到回调、平台 API 缺失、通知失败、固定 tab、ID 编码和方案返回回退。
- [八页数据流](../tools/smoke-pages.js)：实际注册的 7 个来源页面分别验证连续点击只调用一次、等待时切回前台仍不重复、明确失败可重试、成功后不提前解锁、返回后可再次打开、卸载后忽略迟到失败。另通过真实安全抽屉的提交/关闭流程，验证红旗下 6 个候选导航入口不发起跳转。
- 项目检查和完整回归最终均以 0 退出；上阶段的 16 项存储测试、20 次页面异常操作、6 页读取恢复，以及现有内容/安全/私有隔离/隐私删除/回滚测试继续通过。
- 配套平台运行 `tsx --test tests/public-catalog.test.ts`，4 项通过，包括真实 106 行 SQLite → HTTP → 当前小程序目录/详情的链路、服务与数据库重启、版本损坏拒绝和私有资料隔离。微信网络接口仍为测试桥接；没有验证微信 HTTPS 域名访问或手机联网。
- 内容和规则仍为 `.10` 的 12 件制品，106 条历史目录没有重建，公开照片与可发布整方仍为 0。本阶段不改后端、工作数据库或联网配置。
- 本轮源码统计：主包 287,369 字节、食材分包 18,732 字节、官方方案分包 29,260 字节，总计 335,361 字节。微信实际打包大小须由开发者工具另验。

这些验证模拟微信 API 的结果与页面生命周期，不证明真实分包下载、动画、微信页面栈或 Android/iOS 行为。没有微信开发者工具编译或手机录屏时，不将自动结果填为真机通过。由于当前可发布方案为 0，页面集成不伪造公开整方；官方详情的路由和返回分支由专项夹具验证。
