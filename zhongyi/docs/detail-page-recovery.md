# 食材详情恢复与操作前检查

2026-10-08，食材详情页修复安全分流后无法恢复、失效条目残留旧资料，以及操作使用旧安全评价的问题。每次页面重新显示、收藏/对照或复制前，都按当前会话与当前目录重新读取；不会自动清除用户已提交的红旗。

## 状态与操作

详情页不再用“已有 ingredient”作为重新加载的条件。冷启动或已显示页面被红旗阻断后，只要用户明确清除红旗，下一次 `onShow` 就可重新加载。隐私删除本身清除会话并重置页面栈；自动测试额外检查旧详情对象不会恢复已删除的收藏或对照。

红旗或条目不存在时，清空条目、身份/法规/传统资料、用途、加工提示、安全分组、来源数组及来源查找缓存，并刷新导航标题。失效页面不保留上一条资料供复制或收藏；缺失或格式错误的启动参数进入空状态。

收藏、对照、复制来源和复制安全摘要都先执行当前状态检查。新增限制时不能沿用此前的宽松评价；非红旗场景下，已受限条目仍可以从已有收藏或对照中移除。复制的摘要绑定当前评价，不能复制上次页面的安全状态。

页面卸载后拒绝上述迟到操作。分享回调检查当前红旗、页面状态和条目匹配；不满足条件时只返回普通目录入口。分享仅包含公开条目 ID，不携带安全画像。

## 详情章节快捷定位

2026-10-09，详情增加六个快捷入口：本次安全、规范身份、目录状态、食用加工、禁忌提醒和来源审校，文末可返回顶部。资料边界和本次安全状态仍在快捷入口之前；各章节保持展开并按原顺序排列，没有隐藏禁忌或加入嵌套滚动区。按钮允许换行，不使用固定高度。

定位只接受页面预设章节和当前条目ID，点击前重新检查当前目录、红旗和生命周期；红旗清空详情，失效条目进入空状态。收藏/对照记录读取失败不妨碍资料阅读或定位，不改变原有存储操作门禁。没有新增请求、健康字段、存储写入或自动定位。

实现采用`wx.pageScrollTo`的固定选择器与零时长，不按系统名称分支。接口字段核对自[微信官方类型定义](https://raw.githubusercontent.com/wechat-miniprogram/api-typings/master/types/wx/lib.wx.api.d.ts)中的`PageScrollToOption`；官方文档页本轮无法打开，不以类型定义或模拟调用证明微信实际布局。缺失接口、同步异常或失败回调只显示“快捷定位暂不可用，请向下滑动阅读完整资料”，不显示底层错误，不自动重试。每次点击、页面显示/隐藏及内容清空使旧回调失效；同一次请求只接受一次结束结果，另核对条目ID和实时红旗。
