## 只读准备入口

在小程序项目目录运行 `npm.cmd run preflight:device`，实际入口是[准备检查器](../tools/device-preflight.js)。它仅检查本项目固定配置文件，不执行开发者工具、不请求服务、不登录、不上传、不安装，也不读取本地私有配置内容。报告不包含实际AppID、服务URL、私钥或配置中的额外字段。

退出0和 `inspectionSucceeded: true`只表示检查完成。`readyForDeviceAcceptance`、工具执行、设备、部署及专业批准仍为false；即使填写了非游客AppID或HTTPS地址，也只能报告已配置但未核实。若存在本地私有配置，须在开发者工具内核对最终生效配置，不能由基础配置推断覆盖结果。

空服务地址仅阻止联网目录验收，不阻止离线查阅。准备检查也不代替 `npm run check`、完整测试或真正编译；页面/分包数量是配置观察，不是编译包内容与实际大小的证明。[10项专项](../tools/test-device-preflight.js)已全部通过，覆盖游客/缺失标识、HTTPS配置、域名校验关闭、私有覆盖提示、输出脱敏、无自动操作及不能伪造验收状态。新增三端独立门禁不能由配置伪造通过。全部旧原生回归保留，现共26个脚本。
