## 私有数据与自动检查

记录位于 [私有复查数据](../content-private/research-refresh/2026-10-08.json)，与原媒体目录分开，不改写已有候选、科研线索及其生成清单。记录绑定原目录、候选目录和研究目录的文件摘要，以及 `.10` release 和原快照日期；基线变化会要求重新评估，不能静默替换绑定。

新增 `tools/check-research-refresh.js` 与 `tools/test-research-refresh.js`，接入完整 `npm run check` 和 `npm test`，不删除旧测试。检查覆盖私有状态、日期冲突保留、审批分类、未经捕获的摘要/视觉审核拒绝、三个缺口保留，以及上传排除、正式制品与运行代码隔离。

这些离线检查只证明工程边界，不验证网页真实性、医学事实、许可证适用性或真人专业资格，不代表来源独立核验或专业签审完成。查证网页未保存为本地原件，因此不伪造网页内容摘要。

本批实测：新增 10 项测试全部通过；完整 `npm run check` 与 `npm test` 通过，12 件正式制品保持原摘要。首次完整回归在既有审校工具启动子进程时遇到沙箱 EPERM；经许可重跑全部成功，没有跳过该测试或降低断言。五份本批相关文档的 18 个本地链接检查通过。这些结果均为本机验证，未执行远程 CI、容器、公网部署或微信真机验收。
