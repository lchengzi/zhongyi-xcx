# 详情实物照片缺失提示与字段隔离

2026-10-09，食材详情的食用资料区域新增“实物图片暂未提供”提示。它说明当前版本没有可展示的实物照片，并引导阅读部位与加工文字；不把图片缺失解释为加载失败，也不将文字或图片用于采集、鉴别或可食性判断。正式照片候选、三个缺口和公开照片为 0 的状态没有改变。

## 界面与数据边界

提示位于既有食用资料与加工边界内，使用可换行文字，没有图片框、替代插画、远程 URL 或加载按钮，不发起额外请求。未知的图片字段、来源候选的可发布标志、目录在线/离线状态都不能改变这一提示。未来采用真实图片仍需另行建立经审查的公开媒体契约，不能直接放开当前待审字段。

[详情页面逻辑](../subpackages/catalog/detail/detail.js)现在只把标题、状态和操作需要的 16 个字段传给界面，不再整对象展开 `format.detailView`。测试注入额外图片字段后，原有展开会将这些未使用字段带入页面数据；改为明确字段后，这些字段不进入界面。此结果是内存故障注入，不说明正式来源或生产环境已发生泄露，也不替代现有服务目录严格校验。版本化格式化器没有修改。

红旗或失效条目会同时清空照片提示、来源及其他详情；明确清除红旗后再加载合法条目才恢复提示。原有收藏、对照、复制与分享的实时安全检查保留。
