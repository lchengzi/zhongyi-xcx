# 隐私删除操作可靠性

2026-10-09，隐私页将删除确认、实际清理和返回首页分开处理。旧弹窗不能重复删除后来新增的记录；页面隐藏或卸载后不再执行旧确认及旧返回回调。明确取消、红旗下主动删除、读取异常时清理会话的能力仍保留。

## 当前确认与删除

确认框只允许同时存在一个。确认对应当前隐私批次、可读取的本应用键值、读取状态、安全画像、确诊确认、清单及旧版会话字段。不是只比较类别数量，因此收藏数量相同但 ID 不同、用药文字变化、旧版记录变化，都需要重新明确确认。读取持续异常时仍可请求删除，但不能用未知数量证明已全部删除。

确认上下文只在内存中暂存，不写入页面 `data`、弹窗正文、持久化或网络；取消、失败、隐藏、卸载或消费确认时释放。它不是身份认证或健康数据备份。隐私页仍只展示类别、数量和通用状态，不回显健康文字。

确认取消或失败不删除。重复回调及旧操作的失败回调不能覆盖新操作。仅触发 `onShow` 不会解锁仍在等待的确认；实际 `onHide` 会作废它，返回后需要新确认。数据变化时先刷新摘要，再提示重新确认，不自动重弹或执行删除。

删除仍只处理 `zhongyi_` 命名空间及本次会话，不删除其他命名空间。存储删除失败时仍清空会话健康信息、确认和清单，但不显示全部成功或发起返首页；只有删除及验证都完成才报告成功。公开资料缓存取消失败也不阻止尝试清空健康信息，但整体仍报告未验证。异常提示不显示底层错误或真实健康内容。

## 返回首页与失败重试

成功删除优先重启到首页；明确失败后仅尝试一次切换首页。每次返回操作独立识别回调，迟到或重复失败不反复导航；隐藏、卸载后的失败不把用户从其他页面拉回。

两种返回都失败时，页面保留删除结果，并显示可重试的“重新打开首页”按钮。该按钮只导航，不再次清理，后来新建的收藏、对照和健康会话不会因重试返回被删除。返回等待期间禁用重复删除与返回；没有用超时自动发起第二次导航。

系统剪贴板及其他应用中已经粘贴的副本不在删除能力内，原隐私说明保留。微信真实页面栈、后台行为和系统存储仍需设备验证。
