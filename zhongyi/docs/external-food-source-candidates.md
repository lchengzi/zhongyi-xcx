# 配方普通食品官方来源候选（私有研究层）

当前 18 条配方普通食品全部保持 `pending`。本工作流只整理供真人复核的官方标准或目录线索，不把“某类别存在国家标准”自动写成“某条配方食材已经完成身份、法规、食用形态或安全审核”。

候选结构版本：`schemaVersion=1.2.0`  
候选内容版本：`contentVersion=2026.08.13-external-food-source-candidate.6`  
隔离状态：`private / pending`；72 个证据域槽位全部 `ready=false`  
私有目录：`content-private/source-candidates/external-foods/`  
离线审阅：`review-index.html`  
构建：`npm run build:evidence-drafts`  
检查：`node tools/check-external-food-source-candidates.js`  
变异测试：`node tools/test-external-food-source-candidates.js`

## 当前覆盖

- 7 条旧版官方类别/产品范围线索覆盖 14 条普通食品记录；另有 30 条逐目标、逐证据域候选，第四批补充食盐/清水的食用形态与局部安全线索。全部 `publicationEligible=false`、`runtimePlacements=[]`、`directClaimUse=prohibited`。
- 清单为 18 条普通食品显式建立 `identity / regulatory / food_use / safety` 共 72 个域槽；所有槽均保留受控 `residualGapCodes` 且 `ready=false`。候选存在不等于证据域已经关闭。
- 每条证据显式标注 `bibliographic_only / partial / boundary_only`。标准题录只能证明标准名称与生命周期，局部安全提示不能代表完整安全域，仅用于排除错误映射的来源不能充当直接身份证据。
- 黑豆现有两条身份映射候选、一条成人官方食养出现候选和一条过敏风险候选。其中国家粮储局统计制度明确“大豆”包括黑豆，GB 1352-2023 只提供现行大豆产品标准题录；二者仍需联合人工判断，不能取代植物基原、供应批次或标签核验。
- 黑豆安全候选只覆盖大豆类过敏这一部分，不覆盖孕哺、儿童、疾病、用药、污染物或完整加工安全，因此安全域仍未就绪。
- 食盐与清水各有身份、法规、食用形态和局部安全候选，但配方没有给盐种或水源，不能自动等同低钠盐、加碘盐、生活饮用水、包装饮用水或天然矿泉水；健康成人全天食盐建议和家庭饮用水煮沸科普也不得变成单方固定剂量或新增步骤。
- 鸡肉与猪瘦肉现有国家标准题录只提供产品对象和生命周期候选；不证明母鸡性别、去内脏状态、鸡块/肉末加工、具体部位或批次。肉禽蛋熟制提示只覆盖一般加工安全的一部分。
- 粮食候选覆盖黑豆、糯米粉、粳米粉和粳米，但四种形态仍保持独立，精确商品身份待核。
- 芝麻油消费提示可部分支持“香油/芝麻油”名称关系，但仍需标签确认是否纯芝麻油；未指明的“油”只有一条排除错误映射的边界线索，连植物油类别都不能自动确定。
- 酱油、食盐、生活饮用水分别有标准线索，但配方没有给出具体品类或水源，映射仍待核。
- 料酒消费提示可证明市场上至少有三类料酒，恰恰说明原方泛称不能自动映射某一类别；蛋制品许可细则定义的工业液蛋经均质、杀菌等工艺，与原方现打搅匀蛋液不得机械等同。

## 明确缺口

下列 4 条记录仍保留目标级缺口，不能用邻近名称兜底；其中葱已有部分身份线索，但尚不足以关闭缺口：

- 葱：正式题录只证明 NY/T 744-2020 存在且现行；食养指南只提供“葱”在步骤中作为“葱花”使用的实例，仍缺具体物种、食用部位和普通食品范围的直接绑定。
- 葱花：已有官方食养方的使用实例，但没有物种、食用部位或切制规格，不能与泛称“葱”合并。
- 枸杞叶：已有官方食养指南中的煮汤实例，但不能由该实例、枸杞子或“枸杞”通名反向证明物种身份和全国普通食品范围。
- 芹菜：正式题录与食养出现证据已经登记，但最终标准正文、具体食用部位和一般产品范围仍待直接来源。

## 晋级条件

候选来源进入 `data/recipes.js.externalFoods` 前，至少需要：

1. 真人确认来源仍有效，并核对标准正文的适用范围，而不是只看公告标题。
2. 将身份、法规、食用形态/用途和安全证据分域；类别标准不能跨域复用。
3. 保留每条外部食材自己的直接来源对象，且与顶层规范来源对象完全一致。
4. 中医临床、药学与合规三角色分别绑定当前食材摘要、当前规则版本和独立审核记录。
5. 重新运行公开构建；只有被真正发布整方引用的已审记录才可进入客户端。

本工作流不替代专业审核，也不改变当前结果：5 条整方均为隐藏草稿，公开普通食品记录 0，`publishableRecipes=0`。
