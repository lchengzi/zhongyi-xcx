## 本次收口

- 顶层来源、配方内嵌来源和外部普通食品来源使用同一 ID 时，必须是完整规范对象一致，不能只比较 ID。
- 外部普通食品配方行的 `identitySourceIds` 必须来自该食品自己的直接身份来源，并且不能复用仅证明“配方中出现及用量”的指南来源。
- 配方来源 ID 必须唯一；外部食品 schema、类别、数量和逐行出现证据必须在运行时、静态检查器和公开构建器三层一致。
- 公开构建对外部普通食品采用显式字段投影，不复制未知审校字段或私有备注；当前 18 条待审记录仍不会进入客户端公开索引。
- 正向发布夹具由运行时、公开构建器和静态检查器共用；同 ID 漂移、出现证据越权、重复来源、未知私有字段、缺失 registry、未知 schema 和证据覆盖漂移均有负向回归。
