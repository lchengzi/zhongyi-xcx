## 核对意见 API 与表单

独立命名空间`/api/v1/private-photo-notes/:id`，不放宽原图/候选列表的GET-only限制。GET由已登录admin/editor/reviewer读取，响应严格`{schemaVersion: "private-photo-notes.1", candidateId, bindingDigest, version, history}`；最近50条、版本连续，历史可属于旧原图或来源。POST仅admin/editor，可用现有同源Cookie/CSRF，成功201返回完整具名意见。请求只有`{bindingDigest, expectedVersion, category, text, evidenceReference}`：类别identity/processing/rights/general，意见最多1200字、依据最多400字，均非空。

候选由服务端固定registry按ID取出；不接受客户端图片、来源、角色或批准字段。当前完整元数据与原图摘要形成bindingDigest；sourceRevision、作者、许可、疑点或原图变化后旧绑定不能保存。匿名/失效会话401，角色/CSRF/来源/本地密钥403，停用或未知候选404，未知参数/字段/方法/正文400，正文过大413，版本/绑定冲突409。默认不配置私有库不开放新记录。

客户端严格核对回执的候选、输入、下一版本和操作者账号修订，并独立校验历史/回执SHA-256。重新读取不允许版本回退或覆盖仍在窗口内的旧历史。异常回执、错误、取消或结果未知不自动重发；人工读取若找到匹配记录才确认保存，否则保留输入，新的手动提交须单独确认。刷新其他列表不能解除该保护。切候选/重读候选/导航/退出保护当前输入；退出结果未知时关闭原图但保留表单，显式核对有效会话后恢复操作。

历史显示具名意见、依据、原图摘要与来源修订；可展开当时的作者/声明许可及固定oldid文件页。旧绑定明确标为历史，不作为当前核对结论，也不承诺旧原图仍可预览。意见只在内存表单及私有DB中，不进入公开接口、小程序包或真实AI；原图字节不在业务备份中。
